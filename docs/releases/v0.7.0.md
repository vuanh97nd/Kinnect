# Kinnect 0.7.0 — Android testing build

Native Android views updated against the live Kinnect web interface reviewed on 2026-10-27.

- Lavender light/dark surfaces and purple actions across the app, live lobby, music picker and sheets.
- Compact three-column discovery with smaller typography, circular avatars, icon actions and friendship states. Recommended, nearby and following filters match the current web; existing new/online filters remain available.
- Friends list, incoming requests and outgoing invitations are accessible from the account menu; settings now have a dedicated screen with a back action.
- Conversation header shows back, avatar, name and call controls without the global toolbar/bottom navigation.
- Inline message actions: reaction, forward, own-message recall and local deletion. Existing pin/report actions remain on long press. Recalled messages can still be locally deleted and do not render attachments.
- Forward text and attachments to friends, conversations and groups, revalidating the source before sending. Files stay subject to authenticated server access and the existing 20 MB limit.
- Recommended videos use likes × 3 + comments × 2, then newest date and ascending ID. Recommendations wrap after the last video; following stays bounded. Liking a video retains the current video after reranking.
- Refresh unread indicators after marking notifications read; transient network errors do not clear unread counts.
- Constrain reading content to 720 dp and sheets to 560 dp on wider Android screens; video/live stages retain available space.
- Build starts from clean Java/dex output; CI policy checks cover URL validation, release versions and recommendation navigation.

Validation: native APK compiled using Android API 35, min API 26; APK v2/v3 signatures verified; ServerConfigTest, ReleaseVersionTest and VideoFeedPolicyTest passed. Build uses the existing local testing signing key. No physical Android device or emulator was available: camera/microphone, calls, livestream, keyboard/rotation and visual sizing still require device verification. This release does not claim complete parity with every newer web-only feature.
