Kinnect 0.3.1 / versionCode 6 — máy chủ cố định, nhận diện thương hiệu mới, web hoàn thiện hơn.

**Cập nhật backend Windows lên 0.3.1 trước khi dùng APK.** /health phải có version 0.3.1. Giữ đúng DATA_DIR; migration chỉ thêm bảng (thích/bình luận bài viết, yêu cầu quên mật khẩu, liên kết Google/Facebook).

- **Máy chủ mặc định mới: https://app.kinnect.io.vn** (Cloudflare Tunnel cố định, không đổi địa chỉ khi khởi động lại). APK cũ vẫn dùng được: Cài đặt → Đổi máy chủ → nhập địa chỉ trên.
- **Biểu tượng mới**: chữ K trắng trên nền chuyển sắc tím–hồng, dùng chung cho app Android, web và website.
- Bản web (app.kinnect.io.vn): màn giới thiệu, đăng nhập/đăng ký mới, đăng nhập gần đây, quên mật khẩu (quản trị viên cấp mật khẩu tạm), đổi mật khẩu, thích và bình luận bài viết, trang cá nhân có thống kê, thông báo và hộp thư dạng danh sách, menu tài khoản.
- Đăng nhập Google/Facebook có trên bản web khi chủ máy cấu hình `oauth.env`; app Android native chưa hỗ trợ.
- Quản trị: `npm run admin -- create TEN` (mật khẩu qua biến KINNECT_PASSWORD), `npm run admin -- reset-password TEN`, tab Quản trị có mục Yêu cầu quên mật khẩu.
- Chạy ẩn trên Windows: `start-kinnect-hidden.vbs` (server + tunnel), dừng bằng `stop-kinnect.cmd`.
- Màn hình native Android không đổi so với 0.3.0 ngoài biểu tượng và máy chủ mặc định. Live qua Internet vẫn cần TURN/SFU. Chưa kiểm thử trên thiết bị Android thật.
- APK ký bằng khóa debug tạo tạm trên CI như 0.3.0; nếu Android báo khác chữ ký, xem hướng dẫn trong ghi chú 0.3.0 trước khi gỡ bản cũ.
